# MDS Final Report

This repository contains the code, simulated data, outputs and final report for a Monte Carlo study of the reliability of the linear-method precision formula under spatial heterogeneity.

## Main files

- `Report_Zhang_H.Rmd`: source file for the final report.
- `Report_Zhang_H.pdf`: compiled final report.
- `references.bib`: bibliography used by the report.
- `01_run_final_simulation.R`: runs the formal Monte Carlo simulation and writes the raw and summary results.
- `02_make_report_figures.R`: reads the simulation summaries and produces the report figures and tables.
- `03_make_spatial_diagnostics.R`: produces the CSR diagnostic results and figures.
- `wk2_toy_beta.R`: produces the toy spatial-pattern and transect figures.

## Data and outputs

- `outputs/full_R400/`: final simulation results for 400 repetitions per setting, including raw results, summaries, figures and tables.
- `outputs/spatial_diagnostics/`: CSR diagnostic summaries and figures.
- `partB_beta_toy_figures/`: toy figures used in the report.

All data used in the analysis were generated by the simulation scripts. There is no external input dataset.

## Reproducing the report

The analysis was run using R 4.4.2.

To compile the report using the included outputs, run:

```r
rmarkdown::render("Report_Zhang_H.Rmd")
```

To regenerate the complete analysis, run the scripts in this order:

1. `01_run_final_simulation.R`
2. `02_make_report_figures.R`
3. `03_make_spatial_diagnostics.R`
4. `wk2_toy_beta.R`

Then knit `Report_Zhang_H.Rmd`.
